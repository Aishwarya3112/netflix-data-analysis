🎬 Netflix Data Analysis Project

📌 Objective
Analyze Netflix dataset to understand content trends, audience targeting, and global distribution using Python.

🧰 Tools Used
Python
Pandas
Matplotlib

🧹 Data Cleaning
Handled missing values
Removed duplicates
Fixed date formats
Standardized data types

📊 Exploratory Data Analysis
Movies vs TV Shows distribution
Top countries producing content
Ratings analysis (audience targeting)
Genre analysis
Content trend over years

📈 Key Insights
Netflix is more movie-heavy overall
US is the dominant content producer
India is a major growing market
Adult content (TV-MA) dominates
Drama + International content is most common
Content grew rapidly after 2015 and peaked around 2018–2019

🚀 Conclusion
Netflix evolved from a US-centric movie platform into a global streaming service with increasing focus on TV shows and international content.
